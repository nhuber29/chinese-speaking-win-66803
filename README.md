## About Chinese-speaking

Chinese-speaking is designed for learners who want a simple way to practice speaking through short, repeatable exercises in the browser. It is especially useful for people working on pronunciation, timing, and spoken fluency in Chinese or English, since it turns a dialogue into a structured practice session instead of a wall of text.

The tool helps users move from reading to speaking by breaking dialogue into individual sentences, playing them one by one, and supporting shadowing-style repetition. With automatic pronunciation evaluation, it adds immediate feedback to a routine that can otherwise be hard to self-check.

## Features

- Web-based interface that runs in the browser
- Paste a dialogue directly into a text box
- Parse dialogue content into individual sentences
- Play each sentence separately for focused practice
- Supports shadowing-style repetition after playback
- Automatic pronunciation scoring for spoken output
- Useful for both Chinese speaking and English speaking practice
- Simple workflow built around dialogue-based learning

## Usage

1. Open the webpage.
2. Paste a dialogue into the input box.
3. Click the button to parse the dialogue.
4. Review the sentences that are generated.
5. Play each sentence and repeat it aloud.
6. Use the pronunciation score as feedback for another attempt.

A typical practice session looks like this:

- Paste conversation text
- Split it into manageable lines
- Listen sentence by sentence
- Shadow the audio
- Check the speaking score
- Repeat until the result improves
